# 测一测，你适合定居的城市

一个单文件、自包含的 H5 趣味匹配测试：32 道脑洞选择题，为你匹配 20 个中国城市里的「本命城市」。
用于小红书图文 / 短视频引流。纯静态页面，无后端、无数据上报。

## 在线访问

GitHub Pages: <https://ymymaya.github.io/city-home-quiz/>

## 本地运行

直接双击 `index.html` 用浏览器打开即可，无需构建、无需本地服务。

## 内容边界

- 城市池：北京、上海、天津、重庆、广州、成都、长沙、深圳、杭州、大理、西安、厦门、青岛、武汉、苏州、哈尔滨、福州、南京、昆明、兰州。
- 所有城市印象均为正向 / 中性的大众趣味标签，不做地域贬低、道德评判。
- 结果卡可在结果页一键生成（1080px 竖版 PNG），用于小红书发图。

## 文件

- `index.html` — 完整 H5（落地页 / 32 题 / 结果页 / 保存到手机结果卡）
- `城市同频测试-内容包.md` — 小红书图文脚本、短视频分镜、城市人设速查、计分规则
